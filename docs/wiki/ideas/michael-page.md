# Michael Page (PageGroup)

Employment brand: connect companies and professionals. Services are **layered by seniority and motion**, not only by industry.

## What they do

* Professional / management hiring: **permanent**, **temporary**, project/interim.
* Executive: leadership search, executive interim, assessment, advisory, compensation insight, board search.
* Scaled: RPO (recruitment process outsourcing), contingent/MSP, “total talent,” geographic scale.

## Ideas for Tekforce

| Idea | Status | Note |
| --- | --- | --- |
| Permanent vs temporary vs executive as placement types | **v1** | Configurable types (already locked) |
| Executive interim as a type | later | Same pipeline, different SLA and fee |
| Assessment / advisory products | later | Services, not software first |
| RPO / MSP / total-talent outsourcing | later | Process + contracts; software is a module |
| Compensation insight | later | Data product |

## Why it matters

Tekforce’s “CEO Search” is a **Michael Page executive** line. Keep it as a placement type and a vertical, not a separate app. RPO/MSP stay off v1 so we do not build VMS.
